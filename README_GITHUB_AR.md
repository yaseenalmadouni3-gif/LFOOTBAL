# Offline Football Demo

هذا المشروع مجهز كبداية للبناء التلقائي عبر GitHub Actions.

1. أنشئ Repository جديدًا في GitHub.
2. ارفع ملفات المشروع.
3. افتح Actions.
4. اختر Build Android APK.
5. اضغط Run workflow.
6. بعد انتهاء البناء، افتح Artifacts وحمّل ملف APK.

هذه نسخة Prototype وليست اللعبة النهائية.
